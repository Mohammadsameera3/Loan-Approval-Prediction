# Loan Approval Prediction Using Machine Learning

## Overview
This project predicts whether a loan application will be approved based on applicant information using Machine Learning.

## Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Joblib

## Algorithms
- Decision Tree
- Random Forest
- GridSearchCV

## Results
- Tuned Random Forest Accuracy: **78.05%**

## Files
- Loan Prediction.ipynb
- loan_data.csv
- loan_model.pkl
